Privacy Policy: Channel Uploader

Last updated: October 5, 2026

Channel Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channels. It has no other users.

Data accessed

With the owner's permission, the tool uses the YouTube Data API scope https://www.googleapis.com/auth/youtube.upload to upload videos and set their metadata and thumbnails. It does not read, collect or store data about any other person.

Storage

The OAuth token is stored only on the owner's computer. No data is sent to any server other than Google's YouTube API, and nothing is sold or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
